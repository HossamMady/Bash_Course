DAY 01 / FOUNDATIONS

أساسيات Bash والمدخلات

من الدقيقة 00:00 إلى 32:00 — ابني الأساس من الصفر.
7 دروس
01
Shell و Bash و Terminal
الأساس الذي لازم تفهمه قبل كتابة أي Script
⌄
بالمختصر المفيد

الـ Terminal هو المكان أو البرنامج الذي تكتب فيه الأوامر، بينما الـ Shell هو البرنامج الذي يفهم هذه الأوامر وينفذها. Bash هو واحد من أشهر أنواع الـ Shell.

مثال عملي
اضغط على الكود للتجربة 
$ echo $SHELL
/bin/bash
💡 تذكر: Terminal = المكان، Shell = المفسر، Bash = نوع من أنواع الـ Shell.
02
إنشاء أول Script وShebang
إنشاء ملف .sh وتحديد المفسر
⌄
بالمختصر المفيد

ملف الـ Bash Script هو مجرد ملف نصي يحتوي على مجموعة أوامر. امتداد .sh شائع، والـ Shebang يخبر النظام أن الملف يجب تشغيله باستخدام Bash.

إنشاء الملف
اضغط للتجربة 
#!/bin/bash

echo "Hello from Bash!"
💡 قاعدة: أول سطر في السكربت غالبًا يكون: #!/bin/bash
03
الصلاحيات وتشغيل الـ Script
chmod +x وتشغيل الملف مباشرة
⌄
بالمختصر المفيد

Linux لا يعتبر كل ملف قابلًا للتنفيذ تلقائيًا. باستخدام chmod +x نعطي الملف صلاحية التنفيذ.

أوامر التشغيل
اضغط للتجربة 
chmod +x hello.sh

./hello.sh
💡 بديل: يمكنك تشغيل السكربت بدون إعطاءه executable permission عن طريق bash hello.sh.
04
echo و Comments
طباعة المعلومات وكتابة التعليقات
⌄
بالمختصر المفيد

echo يطبع شيئًا على الشاشة. أما # في بداية السطر فيجعل السطر تعليقًا لا ينفذه Bash.

مثال
اضغط للتجربة 
#!/bin/bash

# This is a comment
echo "Welcome Ahmed"
echo "Bash is awesome!"
05
Variables — المتغيرات
تخزين البيانات واستخدامها
⌄
بالمختصر المفيد

المتغير عبارة عن اسم نخزن بداخله قيمة. أهم قاعدة في Bash: لا تضع مسافات حول =.

مثال
اضغط للتجربة 
name="Ahmed"
age=25

echo "Name: $name"
echo "Age: $age"
⚠️ خطأ شائع: name = "Ahmed" خطأ. الصحيح هو name="Ahmed".
06
read — أخذ Input من المستخدم
جعل السكربت تفاعليًا
⌄
بالمختصر المفيد

read يجعل السكربت ينتظر المستخدم لكي يكتب قيمة، ثم يخزنها في متغير.

مثال تفاعلي
اضغط للتجربة 
echo "Enter your name:"
read name

echo "Hello, $name!"
💡 للتطبيق الحقيقي: جرّب كتابة السكربت في WSL ثم نفذه وستتمكن من إدخال قيمة فعلية.
07
Arguments وExit Status
$1 و$2 و$# و$@ و$?
⌄
بالمختصر المفيد

عندما تشغل السكربت وتكتب بعد اسمه قيمًا، هذه تسمى Arguments. أول قيمة هي $1 والثانية $2. $# عددها، و$@ يمثلها كلها. أما $? فهو Exit Status لآخر أمر.

مثال
اضغط للتجربة 
#!/bin/bash

echo "Hello $1"
echo "Location: $2"
echo "Arguments count: $#"

echo "Status: $?"
💡 قاعدة مهمة: في Bash عادةً 0 يعني نجاح، وأي رقم غير صفر غالبًا يدل على وجود مشكلة.

DAY 02 / LOGIC & CONTROL

الشروط والحلقات والملفات

من الدقيقة 01:08:10 إلى 01:34:20 — خلّي السكربت يفكر ويتكرر.
7 دروس
08
if / elif / else
جعل السكربت يتخذ قرارات
⌄
بالمختصر المفيد

الجملة الشرطية تقول للسكربت: "لو الشرط صحيح اعمل كذا، وإلا اعمل كذا".

مثال
اضغط للتجربة 
age=25

if [ "$age" -ge 18 ]; then
    echo "You are an adult."
elif [ "$age" -ge 13 ]; then
    echo "Teenager."
else
    echo "Child."
fi
💡 انتبه: المسافات داخل [ ] مهمة جدًا في Bash.
09
مقارنات الأرقام والنصوص
-eq -ne -gt -lt و = !=
⌄
بالمختصر المفيد

Bash عنده operators مختلفة للأرقام عن النصوص. للأرقام استخدم مثلًا -eq و-gt، وللنصوص استخدم = و!=.

مثال رقمي
اضغط للتجربة 
a=10
b=5

if [ "$a" -gt "$b" ]; then
    echo "$a is greater than $b"
fi
مثال نصي
اضغط للتجربة 
name="Ahmed"

if [ "$name" = "Ahmed" ]; then
    echo "Welcome Ahmed"
fi
10
فحص الملفات والمجلدات
-f و -d لاختبار وجود الملفات والمجلدات
⌄
بالمختصر المفيد

يمكنك سؤال Bash: هل هذا المسار ملف؟ هل هو مجلد؟ باستخدام operators مثل -f و-d.

مثال
اضغط للتجربة 
file="notes.txt"

if [ -f "$file" ]; then
    echo "The file exists."
else
    echo "File not found."
fi
أمثلة إضافية: -d مجلد، -e موجود، -r قابل للقراءة، -x قابل للتنفيذ.
11
&& و || و !
ربط الشروط معًا
⌄
بالمختصر المفيد

&& معناها "والشرطان لازم ينجحوا". || معناها "يكفي واحد". ! تعكس نتيجة الشرط.

مثال
اضغط للتجربة 
age=25
has_id=true

if [ "$age" -ge 18 ] && [ "$has_id" = true ]; then
    echo "Access granted"
fi
12
for و while Loops
تكرار الأوامر بدلًا من كتابتها مرة وراء مرة
⌄
بالمختصر المفيد

for ممتاز عندما تعرف المجموعة التي ستدور عليها. while تستمر طالما الشرط صحيح.

for loop
اضغط للتجربة 
for name in Ahmed Ali Sara; do
    echo "Hello $name"
done
while loop
اضغط للتجربة 
count=1

while [ "$count" -le 3 ]; do
    echo "$count"
    ((count++))
done

echo "Done"
13
break و continue
التحكم في مسار الحلقة
⌄
بالمختصر المفيد

break يخرج من الحلقة بالكامل. continue يتخطى الدورة الحالية ويذهب للتالية.

مثال
اضغط للتجربة 
for n in 1 2 3 4 5; do

    if [ "$n" -eq 3 ]; then
        continue
    fi

    echo "$n"
done
14
case — بناء Menu تفاعلي
بديل مرتب لسلسلة if طويلة
⌄
بالمختصر المفيد

case ممتاز عندما يكون عندك مجموعة خيارات معروفة، مثل Menu فيها Start وStop وExit.

مثال Menu
اضغط للتجربة 
echo "1) Start"
echo "2) Stop"
echo "3) Exit"

read choice

case "$choice" in
    1) echo "Selected: Start" ;;
    2) echo "Selected: Stop" ;;
    3) echo "Selected: Exit" ;;
    *) echo "Invalid option" ;;
esac
💡 نصيحة: case تجعل الـ Menus في Bash أكثر نظافة وأسهل في القراءة.

15
Functions — الدوال
تنظيم الكود وإعادة استخدامه
⌄
بالمختصر المفيد

الـ Function هي جزء من الكود تسميه مرة، ثم تستدعيه كلما احتجته. الـ Parameters تصل داخل الدالة كـ $1 و$2، وreturn يرجع Exit Status.

مثال
اضغط للتجربة 
greet() {
    echo "Hello $1"
}

greet "Ahmed"
greet "Ali"
⚠️ مهم: return في Bash يرجع status code، وليس نصًا مثل بعض لغات البرمجة. لإرجاع نص عادةً استخدم command substitution مثل result=$(function).
16
Arrays — المصفوفات
تخزين أكثر من قيمة في متغير واحد
⌄
بالمختصر المفيد

الـ Array تخليك تخزن مجموعة قيم مع بعض. الوصول يبدأ من index رقم 0.

مثال
اضغط للتجربة 
tools=("Linux" "Bash" "Git" "Docker")

echo "${tools[0]}"

for tool in "${tools[@]}"; do
    echo "$tool"
done
مفيد جدًا: عدد العناصر: ${#tools[@]} وكل العناصر: ${tools[@]}
17
grep و cut و sort و wc
أدوات Bash القوية لمعالجة النصوص
⌄
بالمختصر المفيد

هذه الأدوات من أهم أسباب قوة Shell: grep يبحث، cut يقتطع أجزاء، sort يرتب، wc يعد.

grep
اضغط للتجربة 
printf "Ahmed
Ali
Ahmed
Sara" | grep "Ahmed"
sort + wc
اضغط للتجربة 
printf "Sara
Ahmed
Ali" | sort
printf "Sara
Ahmed
Ali" | wc -l
18
Redirection و Pipes
نقل المخرجات بين الأوامر والملفات
⌄
بالمختصر المفيد

بدل ما تظل النتيجة على الشاشة، يمكنك إرسالها إلى ملف أو إلى أمر آخر. > يكتب من جديد، >> يضيف، و| يرسل Output لأمر آخر.

Redirection
اضغط للتجربة 
echo "First line" > output.txt
echo "Second line" >> output.txt
Pipe
اضغط للتجربة 
printf "Bash
Linux
Docker" | wc -l
💡 2>&1: تعني توجيه Standard Error إلى نفس المكان الذي يذهب إليه Standard Output. مفيدة جدًا مع الـ logs.
19
Debugging باستخدام bash -x
مشاهدة الأوامر أثناء تنفيذها
⌄
بالمختصر المفيد

عندما السكربت لا يعمل كما تتوقع، bash -x يعرض لك الأوامر بعد توسعة المتغيرات أثناء التنفيذ. هذا يجعل تتبع الخطأ أسهل.

مثال
اضغط للتجربة 
#!/bin/bash

name="Ahmed"
echo "Hello $name"
التشغيل مع Debugging
الأمر المهم 
bash -x script.sh
20
تجميع الأدوات في Automation Script
تحويل المهارات السابقة إلى أداة عملية
⌄
بالمختصر المفيد

قوة Bash تظهر عندما تجمع Variables + Functions + Conditions + Loops + Commands في Script واحد يقوم بمهمة كاملة تلقائيًا.

مثال Automation بسيط
اضغط للتجربة 
#!/bin/bash

echo "System check"
echo "Date: $(date)"
echo "User: $USER"

if command -v bash >/dev/null 2>&1; then
    echo "Bash is installed."
fi

echo "Check completed successfully."

التحدي النهائي — Bash Mini Project
اجمع كل ما تعلمته في مشروع واحد
⌄
🎯 المطلوب

اكتب Script يعرض Menu للمستخدم، ويحتوي على Functions، ويستقبل اختيار المستخدم باستخدام read، ثم يستخدم case لتنفيذ العمليات. اجعل السكربت يتكرر حتى يختار المستخدم Exit.

بداية مشروع مقترحة
اضغط للتجربة 
#!/bin/bash

show_menu() {
    echo "===== Bash Toolkit ====="
    echo "1) System Info"
    echo "2) Current Directory"
    echo "3) Exit"
    echo "========================"
}

while true; do

    show_menu
    read -p "Choose: " choice

    case "$choice" in
        1)
            echo "System information goes here..."
            ;;
        2)
            pwd
            ;;
        3)
            echo "Goodbye!"
            break
            ;;
        *)
            echo "Invalid option."
            ;;
    esac

done
🏆 بعد إنهاء المشروع: أنت الآن قادر على بناء Scripts صغيرة لأتمتة المهام المتكررة في Linux وWSL، وهي نقطة بداية ممتازة للتعمق أكثر في Bash.
